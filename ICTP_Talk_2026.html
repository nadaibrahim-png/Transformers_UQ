The Calibration Problem

MOTIVATION 1:00 – 2:00

Modern deep learning models are accurate but overconfident. A model that says "95% certain" should be right 95% of the time — but often it's right only 70%.

In high-energy physics, miscalibrated confidence scores can bias discovery pipelines — the rare signal events we care most about get drowned out.

ECE = Σ (|Bₘ| / n) · |acc(Bₘ) − conf(Bₘ)|

ECE measures the weighted average gap between confidence and accuracy across bins. Lower = better calibrated.

Problem
A model with 93% accuracy and ECE = 0.016 is telling you wrong confidence levels on thousands of events per batch.
Goal
Find calibration methods that work for both classes — not just the majority background.

Why FT-Transformer over TabTransformer?

TabTransformer only embeds categorical features. FT-Transformer gives every numerical feature — all 50 — its own learned embedding. Stronger representational power for physics data.

CLS token role

A learnable vector that acts as a "listener" — collects from all 50 feature tokens via attention. Its final state → classifier. Borrowed from BERT.

Residual connections

output = LayerNorm(x + Sublayer(x))
Gradient highway: ∂L/∂x always has a constant 1 term — prevents vanishing gradients in deep stacks.

GELU vs ReLU

GELU = x · Φ(x). Smooth gating — no dead neurons. Better for near-zero activations common in attention layers.

Self-Attention — How It Works

MODEL 5:00 – 6:00
The math
## For each token i in our 51 tokens: Q = token × W_Q # "what I'm looking for" K = token × W_K # "what I offer" V = token × W_V # "what I actually give" score(i,j) = (Qᵢ · Kⱼ) / √d_k attention = softmax(scores) output = Σ attention_weights × V

Each feature token learns to ask for relevant information from every other feature. The CLS token aggregates the whole picture.

What this means for neutrino classification

Feature 12 (ring radius) can attend strongly to Feature 31 (shower elongation) — capturing non-linear correlations between kinematic observables that a standard MLP treats independently.

Multi-head (8 heads)

Each head learns a different relationship subspace. Head 1 might capture shape correlations; head 5 might capture timing patterns. Their outputs are concatenated.

√d_k scaling

Without it, dot products grow with dimension → softmax saturates → vanishing gradients. Scaling keeps gradients healthy.

Four Uncertainty Quantification Methods

UQ METHODS 6:00 – 8:00

① Standard

Softmax output used directly. No post-hoc calibration. Baseline.


Pro: Zero cost
Con: Overconfident

② MC Dropout

Dropout active at inference. T=30 stochastic passes. Mean ± variance.


Pro: Epistemic uncertainty, OOD-aware
Con: 30× slower

③ Temp. Scaling

Divide logits by scalar T=1.282 learned on val set. No retraining needed.


Pro: Simple, best overall ECE
Con: Hides per-class failure ⚠

④ Isotonic Reg.

Non-parametric monotonic mapping from confidence to accuracy.


Pro: Flexible
Con: Can overfit minority class

MC Dropout: p̄ = (1/T) Σ f_θ(x; dropout)  |  Var = (1/T) Σ (fₜ − p̄)²

OOD Detection via Predictive Entropy

OOD 12:00 – 13:00
Setup

MC Dropout gives us T=30 probability vectors per event. From their mean p̄ we compute predictive entropy:

H = −Σ p̄ₖ · log(p̄ₖ)

High entropy → model is uncertain → likely OOD. We simulate OOD by adding Gaussian noise (σ=3.0) to all 50 features.

Why MC Dropout enables this

Standard softmax gives one deterministic confidence. MC Dropout's variance captures the model's genuine uncertainty across random network configurations.

Results
H ≈ 0.034
Median entropy — In-Distribution events. Model is confident and certain.
H ≈ 0.347
Median entropy — OOD events. Model spreads probability mass — it knows something is off.
10.2× separation
OOD entropy is 10× higher. Clear discriminative signal without any OOD training examples.

Extended Evaluation

RESULTS 13:00 – 14:00

Noise Robustness Sweep

Added Gaussian noise σ=0.5→3.0 to test features. ECE degrades gracefully. MC Dropout entropy rises monotonically — excellent noise detector.

Ablation Study

Removed attention heads one by one. Performance drops sharply below 4 heads. 8 heads is the sweet spot for 50 features.

Attention Heatmap

CLS token attends highest to features 8, 19, 31 (shower energy, ring shape, elongation) — physically interpretable.

Balanced Accuracy

Mean of per-class recall. ~93.4% across all methods. Calibration doesn't change argmax predictions — only confidence values.

NLL Comparison

Standard: 0.178. TS: 0.136 (best). NLL penalizes confident errors more than ECE — TS still wins, but margin narrows.

Brier Score

MSE of probability forecasts. Standard: 0.071. TS: 0.052 (best). Proper scoring rule — agrees with ECE ranking here.

Conclusions

CONCLUSIONS 14:00 – 14:30
What we found
  • FT-Transformer achieves 93.4% balanced accuracy on MiniBooNE — competitive with gradient-boosted trees.
  • Temperature Scaling gives best overall ECE (↓87%) with minimal overhead — but hides a class-fairness failure.
  • MC Dropout uniquely enables OOD detection: 10.2× entropy separation with no OOD training data.
  • Aggregate ECE with imbalanced classes is a misleading metric. Always check per-class calibration.
Recommendations

Use TS when…

Overall calibration is the goal and classes are roughly balanced. Single-parameter, zero retraining cost.

Use MC Dropout when…

OOD detection matters, or decisions affect the rare class (νₑ signal). Pay the 30× inference cost.

Never trust aggregate ECE alone with imbalanced classes.

Future Work

FUTURE 14:30 – 15:00

Class-conditional Temperature Scaling

Learn a separate Tₖ per class instead of one global T. Directly addresses the νₑ vs νμ calibration trade-off we identified.

Multi-seed experiments

All results are single-seed. Run ×5 seeds to report confidence intervals on ECE, NLL, Brier — more statistically rigorous claim.

Physical OOD scenarios

Current OOD = Gaussian noise σ=3. Replace with realistic physics OOD: different beam conditions, detector ageing, new oscillation channels.

Per-class uncertainty (MC Dropout)

Measure epistemic variance per class separately. Does MC Dropout know it's uncertain about νₑ events? Breakdown not yet done.
